      この教材の対応範囲とデータ保存
      UBNF のリテラル、宣言的 token、参照、選択、繰り返し、capture、text / node の mapping が対象です。import、host binding、状態付きの機能、text / node が混在する capture などは学習エンジンで明示的に拒否します。一般の UBNF は CLI / VS Code で利用できます。
      文法 16 KiB、入力 8 KiB、1 回のチェック 5 秒、WASM メモリ 256 MiB まで。実行の打ち切りは「不一致」と区別します。コードを JavaScript として実行することはありません。進捗はシナリオのバージョンごとにこのブラウザへ保存します。ブラウザのサイトデータを削除すると進捗も消えます。評価器は教材固有で、任意の UBNF に意味を付けるものではありません。
