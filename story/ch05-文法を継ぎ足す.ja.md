# 第五章　文法を継ぎ足す

> 視点：結城灯里

因幡さん——玲とは、あの勉強会のあと、ときどき文法を送り合うようになった。

彼女が送ってきた ANTLR の文法は、たしかに、美しかった。三行で、わたしが二日かけたものと同じことが書いてある。`expr` `term` `factor`。母の図面みたい、と彼女は言った。線の一本に理由がある、と。

わたしは少し、しょげた。手で部品を組む、わたしのやり方は、やっぱり中世なんだろうか。

そのことを槙野さんに愚痴ったら、彼女はにやりとして、「灯里ちゃん、Unlaxer にもね、**紙から作る**やり方、あるんだよ」と言った。

* * *

それが、UBNF だった。

槙野さんがエディタに開いてみせたのは、玲の文法と、おどろくほど似た、一枚の紙だった。規則を、上から書いていく。

```
Expression ::= Term { ('+' | '-') Term } ;
Term       ::= Factor { ('*' | '/') Factor } ;
Factor     ::= Number | '(' Expression ')' ;
```

「これを保存して、ボタンを押すと——」槙野さんがコマンドを叩いた。「パーサーも、さっきの『木』も、木を歩く係も、ぜんぶ、**自動で書き出される**」

わたしは、目を疑った。

「じゃあ……わたしが二日間、手で組んだのは」

「むだじゃないよ」と槙野さんは即座に言った。「だってこの紙から出てくるのも、灯里ちゃんが手で組んだのと**同じ部品**——Chain と Choice と OneOrMore——なんだ。UBNF は、その組み立てを、灯里ちゃんの代わりにやってくれてるだけ。中で何が起きてるか、灯里ちゃんはもう、知ってる」

そうか、とわたしは思った。玲は、生成された何千行を読んだことがないと言っていた。でもわたしは、生成された部品の中を、もう歩いたことがある。同じ「自動生成」でも、わたしには、底が見えている。

——手で組んだ二日間は、底を見るための二日間だったんだ。

そう思ったら、しょげていた気持ちが、すっと軽くなった。

* * *

ここからは、楽しかった。文法を、継ぎ足していくのだ。

まず、変数。`$price` みたいに、あとから値を入れられる箱。紙に一行、書き足す。

```
Factor ::= Number | VariableRef | '(' Expression ')' ;
```

ボタン。`$price * 2` が、動く。たった一行で、世界がひとつ広がる。

つぎに、関数。`abs(-3)` とか、`pow(2, 3)` とか。これも、紙に書き足すだけ。

調子に乗ったわたしは、関数の引数を、ものすごく丁寧に、あらゆる場合を想定して書こうとした。引数が0個のとき、1個のとき、2個のとき、カンマの前に空白があるとき、ないとき……規則が、どんどん枝分かれして、紙が真っ黒になっていく。

そこへ、通りかかったのが、三上さんだった。

* * *

三上さんは、いつも紅茶を持っている、もの静かな先輩だ。あまり喋らない。でも、たまに口を開くと、たいてい、何かが消える。

わたしの真っ黒な紙を、ふうっとひと息で眺めて、三上さんは言った。

「結城さん。それ、**要りますか**?」

「え……あの、引数が0個から3個まで、ぜんぶ場合分けして……」

「『引数を、カンマで区切って、ゼロ個以上』。それだけでいいのでは。0個も、3個も、その一行に含まれてますよ」

```
Arguments ::= '(' { Argument { ',' Argument } } ')' ;
```

わたしは、自分の真っ黒な紙と、三上さんの一行を見くらべた。同じことだった。わたしは、「ゼロ個以上のくりかえし」という、きのう覚えたばかりの ZeroOrMore を、すっかり忘れて、手で場合分けしていた。

「……ぜんぶ、消せます」

「消せるものは、消したほうがいい」と三上さんは紅茶を一口飲んだ。「書かなかったものは、壊れませんから」

書かなかったものは、壊れない。わたしはそれも、ルール帳に書き写した。前任者の丸い字の下が、わたしの字で、少しずつ埋まっていく。

* * *

つぎは、いよいよ `if` だった。

```
if ( 条件 ) { 真のとき } else { 偽のとき }
```

これを紙に書くのは、思ったより、すんなりいった。条件は——条件って、何だろう。`1 > 0` とか、`$x == 5` とか。「大きい」「等しい」を比べる式。それは、数の式とは別の、新しい木だ。比較の木。

わたしは、その夜、玲にメッセージを送った。

「`if` を入れました。条件のところ、ANTLR だとどう書きますか」

返事は、いつもより少し長かった。彼女も、同じところで悩んだことがあるらしい。`if` の条件を、数の式とごちゃ混ぜにすると、文法が曖昧になる、と。`1 > 0 + 1` は、「1 > 0」に「+1」なのか、「1 > (0+1)」なのか。道具が、どっちか分からなくなる。

「あなたの三階建て、ここで効いてくるよ」と玲は書いていた。「比較を、足し算より**上の階**に置けばいい。比較の階は、足し算の階に『中身よろしく』って渡すだけ。あなたの建物の話と、同じ」

わたしは、おどろいた。玲は、わたしの「三階建て」を、ちゃんと覚えていてくれた。そして、それを使って、自分の流派の問題まで、説明してくれた。

違う神様のはずなのに。お経の言葉が、半分、同じだった。

「因幡さんって」とわたしは打った。「ほんとは、手で組むの、嫌いじゃないでしょう」

既読がついて、しばらく、返事は来なかった。それから、ひとことだけ。

「……うるさい」

なんだか、その三点リーダーが、すごく、かわいかった。

——わたしたちは、まだ、自分たちが何に向かって文法を継ぎ足しているのか、知らなかった。継ぎ足した先に、文字列があって、スライスがあって、そしてあの、五十三分の塔があることを。

*(第六章へつづく)*
