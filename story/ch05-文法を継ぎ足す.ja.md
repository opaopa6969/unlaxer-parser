# 第五章　文法を継ぎ足す

> 視点：結城灯里
> （手を動かしながら読めます → `story/code/calc.ubnf` / `story/code/TinyCalcRun.java`）

「手で組むのは、もう十分やった」と槙野さんは言った。「次は、**文法を一枚の紙に書いて、木も、歩く係も、機械に生成させる**」

手で潰した平らな木の、あの「また9」が、まだ胸に残っていた。だから、その言葉は、救いみたいに聞こえた。

「玲ちゃんの言ってた『生成』を、合成派のやり方で。——UBNF っていう紙だよ」

## 一枚の紙

UBNF は、おどろくほど、わたしの「三階建て」そのままだった。

```
grammar TinyCalc {
  @package: story.calc
  @whitespace: javaStyle
  token NUMBER = org.unlaxer.parser.elementary.NumberParser
  token EOF    = org.unlaxer.parser.elementary.EndOfSourceParser

  @root
  Formula ::= Expression EOF ;

  Expression ::= ... ;   // 3階：足し算・引き算
  Term       ::= ... ;   // 2階：かけ算・割り算
  Factor     ::= NUMBER | '(' Expression ')' ;   // 1階
  AddOp ::= '+' | '-' ;
  MulOp ::= '*' | '/' ;
}
```

「Expression と Term の中身は、灯里ちゃんが書いてみて」

わたしは、迷わず、こう書いた。数学の教科書に書いてあった、いちばん「自然」な書き方で。

```
Expression ::= Expression AddOp Term | Term ;
Term       ::= Term MulOp Factor | Factor ;
```

「式は、『式 ＋ 項』か、または『項』」。読み下すと、日本語としても、すっと通る。我ながら、きれいに書けた、と思った。

## 謎のエラー

紙ができたら、あとはボタンひとつ。槙野さんが、生成のコマンドを叩いた。

```
java ... org.unlaxer.dsl.CodegenMain --grammar calc.ubnf --output gen --generators Parser,AST,Mapper
```

```
Generated: .../story/calc/TinyCalcParsers.java
Generated: .../story/calc/TinyCalcAST.java
Generated: .../story/calc/TinyCalcMapper.java
```

すんなり、生成された。三つのファイルが、機械の手で書き出される。わたしは、ちょっと感動していた。一枚の紙が、パーサーになった。

`1+2*3` を、生成された係に流す。

```
IllegalStateException: transaction nest is illegal. check source code.
```

……トランザクション・ネスト・イズ・イリーガル。

なんだ、これは。式エンジンに、数式を一個入れただけ。なのに、英語で、何かを、強く叱られている。「ソースコードを確認しろ」。確認しろと言われても、わたしのソースは、たった六行の、きれいな紙だ。どこが悪いのか、まるで見当がつかない。

机の下のわたしが、また、顔を出しかけた。せっかく生成は通ったのに。文法は、こんなにきれいなのに。

## みんな、ここで踏み抜く

野中くんが、すぐに首を突っ込んできた。「うわ、何これ。トランザクション? 数式にトランザクションって……」。彼も分からないらしい。二人で画面をにらんでいると、槙野さんが、湯のみ片手にやってきて、紙を一目見て——また、笑った。

「あー。**左再帰**だ」

「さ、さいき?」

「`Expression ::= Expression …`。いちばん最初に、また自分自身を呼んでる。`Expression` を読むには、まず `Expression` を読む。読むには、まず読む。読むには——」

「……一文字も進まないまま、永遠に自分を呼ぶ」

「そう。機械は、一歩も食べずに、自分の中へ落ちていく。Unlaxer はそれを途中で『おかしい』って気づいて、あの謎のエラーを吐く。——これね」と槙野さんは、わたしの肩を、ぽんと叩いた。「**パーサー書く人間が、いちばん最初に踏み抜く床のひとつ**。数学で自然な書き方が、機械には、いちばん危ない。私も踏んだ。玲ちゃんに訊いてごらん、生成派でも踏むから」

ちょうど、画面の向こうに現れた玲が、すました顔で言った。「……ANTLR は左再帰、けっこう面倒みてくれるけどね」。それから、小さく付け足した。「……でも、昔、一回、丸一日溶かした」

槙野さんが、にやりとした。「ほら」

## 反復に、書き直す

直し方は、わたしが**もう知っていた**。第二章で、手で組んだとき。三階建ては「自分をもう一度呼ぶ」んじゃなくて、「**ひとつ読んで、あとはくりかえす**」だった。`Term { ＋ Term }`。あの `ZeroOrMore`。

紙を、こう直す。

```
Expression ::= Term @left { AddOp @op Term @right } ;   // 項、そのあと「＋ 項」のくりかえし
Term       ::= Factor @left { MulOp @op Factor @right } ; // 因子、そのあと「× 因子」のくりかえし
```

`@left` `@op` `@right` は、「この部分に名前をつけて、AST に残してね」という印。手で組んだとき、構造が平らに潰れて泣いたから——今度は、名前をつけて、構造を、ちゃんと残してもらう。

`@mapping` も足す。「この規則は、`AddExpr` っていう形の木にしてね」と。

```
@mapping(AddExpr, params=[left, op, right])
Expression ::= Term @left { AddOp @op Term @right } ;
```

生成し直して、`1+2*3` を流す。

```
1+2*3 = 7.0   (AST: AddExpr)
```

七。

今度こそ、七だった。しかも——平らじゃない。

## 平らじゃない木

生成された AST を、のぞいてみる。

```
AddExpr(           ← 足し算の階
  left  = MulExpr("1")          // 1
  op    = ["+"]
  right = [ MulExpr("2",["*"],["3"]) ]   // 2*3 ← かけ算が、ちゃんと下にいる！
)
```

第三章で、わたしが手で潰してしまった構造が、ここには、ちゃんとあった。`2*3` が、`+` の下の枝に、まとまっている。歩けば——子に値を訊いて、まとめるだけで——自然に、七になる。あの「また9」の夜の、答え合わせが、やっと、ついた。

> **手を動かす人へ。** この一連——一枚の UBNF から生成して、構造つき AST を歩いて 7 を出す——は、`story/code/calc.ubnf` と `story/code/TinyCalcRun.java` でそのまま追体験できます（生成→コンパイル→実行の手順はファイル冒頭に）。
> ついでに、`story/code/calc-leftrec.ubnf`（左再帰版）も同梱しました。**ぜひ一度、自分の手で `transaction nest is illegal` を踏み抜いてみてください。** 踏み抜いた人だけが、反復形のありがたみを、骨で覚えます。

## 継ぎ足す喜び

ここからは、楽しかった。文法は、紙に一行足すだけで、育っていく。

変数。`$price` みたいに、あとから値を入れる箱。

```
Factor ::= NUMBER | VariableRef | '(' Expression ')' ;
VariableRef ::= '$' IDENTIFIER @name ;
```

ボタン。`$price * 2` が動く。一行で、世界がひとつ広がる。

関数。`abs(-3)`、`pow(2,3)`。これも、一行。調子に乗ったわたしは、引数を「0個のとき」「1個のとき」「2個のとき」「カンマの前に空白が……」と、あらゆる場合を丁寧に書き分けようとして、紙を真っ黒にした。

通りかかった三上さんが、紅茶を片手に、ふうっとひと息で言った。

「結城さん。それ、**要りますか**?」

「……あの、引数の個数を、ぜんぶ場合分けして」

「『引数を、カンマで区切って、ゼロ個以上』。それだけでは。0個も3個も、その一行に含まれてますよ。——`{ Argument { ',' Argument } }`」

わたしの真っ黒な紙が、一行に縮んだ。第二章で覚えた `ZeroOrMore` を、わたしはまた、忘れて、手で場合分けしていた。

「消せるものは、消したほうがいい」と三上さんは紅茶を一口飲んだ。「書かなかったものは、壊れませんから」

書かなかったものは、壊れない。ルール帳の、前任者の丸い字の下が、わたしの字で、また一行、埋まった。

## 紙が、育っていく

その夜、玲にメッセージを送った。「UBNF、左再帰で一回死にました」。

既読。しばらく間があって、「……でしょうね」とだけ返ってきた。それから、めずらしく長文が来た。母の図面の話。線の一本に理由がある。気分で引いた線は、住む人が苦労する。「左再帰はね」と玲は書いていた。「『気分で引いた線』なの。自然に見えて、住めない。あなたが反復に直したのは、住める線にしたってこと」

住める線。わたしは、その言い方が、好きだった。違う流派の子の言葉なのに、わたしの紙の、芯を、まっすぐ射抜いていた。

——この一枚の紙は、これから、変数を、関数を、`if` を、三項を、文字列を、スライスを、そして——あの、五十三分の塔を、ぜんぶ抱えるまでに、育っていく。育ちすぎた紙が、いつか機械を窒息させることも、このときのわたしは、まだ知らない。
