# 第六章　三項とカッコの掟

> 視点：結城灯里

三項演算子、というものを知ったのは、玲からだった。

`条件 ? これ : あれ`。条件が本当ならこれ、嘘ならあれ。`if` を、ぎゅっと一行に縮めたみたいなやつだ。「現場の人、これ好きだよ」と玲は言った。「短いから」。

わたしは、さっそく紙に書き足した。短い式だから、簡単だと思った。

```
Ternary ::= 条件 '?' Expression ':' Expression ;
```

ボタン。`1 > 0 ? 10 : 20` を入れる。`10`。動いた。やった、と思った。

——その「やった」が、いちばん危ない、と教えてくれたのは、ソクラテスだった。

* * *

ソクラテスは、社の人ではない。勉強会に、ときどき現れる、変な人だ。肩書きも分からない。ただ、誰かが「分かった気」になっていると、どこからともなく現れて、質問だけして、去っていく。みんな、彼が来ると、少し背筋を伸ばす。

その日、わたしが「三項、入りました」と嬉しそうに報告すると、ソクラテスは、にこにこしながら訊いた。

「結城くん。`a ? b : c ? d : e` は、どういう意味かね」

わたしは画面を見た。`? :` が、ふたつある。

「えっと……`a` が本当なら `b`。嘘なら……`c ? d : e`?」

「ほう。なぜ、後ろのほうが、ひとかたまりだと?」

「なんとなく、です」

「なんとなく、で機械は動かんよ」とソクラテスは微笑んだ。「機械は、こうも読める。`(a ? b : c) ? d : e`。前のほうを、ひとかたまりに。——君の紙は、**どちらだと言っているのかね**」

わたしは、自分の書いた一行を見た。`条件 ? Expression : Expression`。Expression の中には、また三項が入れる。前にも、後ろにも。だから——わたしの紙は、**どちらとも言っていなかった**。機械は、迷う。迷ったまま、たぶん、どちらかに転ぶ。気分で。母が嫌った、気分で引いた線みたいに。

* * *

「もっと意地悪を言おう」とソクラテスは続けた。「`1 + 1 ? 2 : 3 * 3`。これは、どこからどこまでが三項かね」

頭が、くらくらした。`1 + 1` までが条件? `3 * 3` までが「あれ」? それとも、`1 + (1 ? 2 : 3) * 3`? 三項が、足し算やかけ算と、どこで境界を引くのか、わたしの紙は、何も言っていない。`?` と `:` が、まるで、闇の中で手探りしているみたいだった。

「これは、昔から有名な、苦しみでね」とソクラテスは言った。「条件分岐を、自由に式の中に置くと、**どこで終わるのか**が、誰にも分からなくなる。君だけの罪ではない。賢い人たちが、何十年も、これで転んできた」

「……どうすれば、いいんですか」

ソクラテスは、答えなかった。代わりに、こう訊いた。

「君はこの前、カッコを、何と呼んだかね」

* * *

——通り道の、設計図。

カッコは、禁止じゃなかった。`(1 + 2) * 3` の、あのカッコ。あれは、「ここからここまでが、ひとかたまり」と、**はっきり囲ってくれる**しるしだった。迷いを、なくしてくれるしるし。

「……三項に、カッコを、必ずつけさせれば」

口に出しながら、わたしは紙を直していた。三項を、裸では置かせない。かならず、外側をカッコで囲ませる。

```
Ternary ::= '(' 条件 '?' Expression ':' Expression ')' ;
```

`(a ? b : c)` は、ひとかたまり。`(a ? b : (c ? d : e))` も、迷わない。カッコが、境界を、ぜんぶ引いてくれる。`1 + (1 ? 2 : 3) * 3` も、もう手探りじゃない。カッコの中だけが三項で、外は、いつもの三階建て。

入れてみる。裸の `1 > 0 ? 10 : 20` は——わざと、エラーにした。「三項にはカッコが要ります」と。

ソクラテスは、満足そうにうなずいた。

「不便だと、思うかね」

「……思います。一文字、多いから」

「その一文字が、君の言語から、**永遠に、ひとつの曖昧さを消した**。安いものだ」

* * *

あとで、玲にこの話をしたら、彼女は少し、むずかしい顔をした。

「ANTLR だと、優先順位と『貪欲に長く取る』って規則で、カッコなしでも、いちおう、決められるよ。`a ? b : c ? d : e` は右に寄せる、って」

「じゃあ、玲のほうが、便利?」

「便利。でも」と玲は、めずらしく、言いよどんだ。「便利な分、その『右に寄せる』っていう決まりが、**文法の紙の外**にあるの。紙を読んだだけじゃ、分からない。道具の、奥のほうのルール。……あなたのは、カッコがあるから、紙を読めば、誰でも分かる」

紙を読めば、誰でも分かる。

それは、玲がいちばん大事にしている、母の図面の言葉だった。彼女は、自分の流派より、わたしの「カッコの掟」のほうが、その言葉に忠実だと、認めてしまったのだ。言ってから、彼女は「……今のは、なし」と打った。わたしは「録画してました」と返した。「最低」と返ってきた。最低、の語尾に、笑っているのが、なぜか分かった。

——後になって、わたしはこの「カッコの掟」に、何度も救われることになる。あの五十三分の塔は、`if` と三項と比較が、めちゃくちゃに積み上がった構造をしていた。もしカッコの掟がなかったら、塔は、固まる前に、そもそも**意味が定まらなかった**だろう。掟は、塔を、かろうじて建っていられるようにしていた。——固まったまま、ではあったけれど。

*(第七章へつづく)*
