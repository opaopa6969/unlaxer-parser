# 第三章　木の中を歩く

> 視点：結城灯里

「7」が出た翌朝、わたしは少し調子に乗っていたと思う。

優先順位の山を越えた。三階建ての建物。形の深さ。もう怖くない——そんな顔をしていたのだろう。槙野さんは缶コーヒーを片手に、わたしの画面をのぞきこんで、いじわるそうに笑った。

「灯里ちゃん、その『建物』、いまどこにある?」

「……えっと、頭の中、ですけど」

「機械の中には?」

わたしは黙った。たしかに、わたしが書いたのは「読む順番」だけだった。建物そのものは、わたしの頭の中にしかない。機械は、それを持っていない。

「読んだ意味は、どこかに**残しておかないと**、使えないんだ」と槙野さんは言った。「で、その残し方が——木」

* * *

木、と聞いて、わたしは校庭のけやきを思い浮かべた。槙野さんが描いたのは、それを上下さかさまにした絵だった。いちばん上に、ひとつの点。そこから枝が下に伸びて、また分かれて。

`1 + 2 * 3` を、彼女はその木にした。

```
        (＋)
        /  \
       1   (×)
           / \
          2   3
```

「いちばん上が『＋』。これが、この式の**いちばん最後にやること**。＋の左の枝が 1、右の枝が……」

「`2 × 3` の、木」

「そう。きのうの三階建てを、横から見ただけ。3階の＋が天辺で、2階の×がその下にぶらさがってる。**建物を倒すと、木になる**」

倒すと、木になる。わたしは、きのうの建物の絵と、いまの木の絵を、頭の中で重ねた。ほんとうだ。同じものだった。階の深さは、枝の深さ。下の階に住んでいた×は、木の下のほうにぶらさがっている。

「この木はね」と槙野さんは続けた。「式の、よけいなものを全部そぎ落としてある。空白も、カッコも、もう要らない。だってカッコは『×を先に』って**位置で**もう表現できてるから。意味の、骨だけ。これを——AST、抽象構文木って呼ぶ」

抽象構文木。また知らない言葉が増えた。でも今度は、手のひらの小石が、少しあたたかい気がした。

* * *

「で、ここからが、きのうの宿題のつづき。この木から、どうやって『7』を出す?」

わたしは少し考えた。木を、上から見る。いちばん上は＋。でも、＋をやるには、左と右の数がいる。左は1、これはいい。右は……×の木だ。まだ数になっていない。

「右の、×を、先に……」

「どうやって右にたどりつく?」

「下に、降りる」

言いながら、わたしは気づいた。＋を計算するには、その下の×を計算しないといけない。×を計算するには、その下の 2 と 3 がいる。**上の答えを出すには、先に下に降りないといけない**。降りて、降りて、いちばん下の数字までたどりついて、そこから答えを抱えて、上に帰ってくる。

「……木の、中を、歩くんですね」

槙野さんの手が止まった。コーヒーの缶を、机にそっと置いた。

「そう。それ。**木は外から眺めるな、中を歩け**」

彼女は、わたしが初めて見る、まじめな目をしていた。

「外から『これは＋の式だな』って眺めてるだけじゃ、答えは出ない。天辺の＋に立って、左の枝を降りて、1を拾って、戻って、右の枝を降りて、その下の×に立って、また降りて、2と3を拾って、6にして、抱えて戻って——やっと、1たす6。**歩いた者にしか、7は出せない**」

* * *

その日、わたしは生まれて初めて、「木の中を歩く」コードを書いた。むずかしいことは何もなかった。一本の、短い決まりごと。

> ある点に立ったら、まず子どもたちに「あなたの値は?」と訊く。子どもが答えてくれたら、その答えを、自分の記号でまとめる。

ただそれだけ。＋の点は、左の子と右の子に値を訊く。右の子（×）も、同じように、自分の子に値を訊く。同じ決まりが、木の上から下まで、こだまみたいに繰り返される。いちばん下の数字の子だけは、訊かれても子どもがいないから、「わたしは2です」と自分の値をそのまま返す。

`1 + 2 * 3` を歩かせた。`7`。
`(1 + 2) * 3` を歩かせた。`9`。
`1 + 2 + 3 + 4` も、`2 * 3 * 4` も、ぜんぶ、正しく歩いてくれた。

ひとつの短い決まりが、どんな形の木でも歩ける。わたしは、それがふしぎでたまらなかった。きのうまで `if` で枝分かれを足し続けて溺れていたのに、木にしてしまえば、決まりはたったひとつでよかった。

* * *

帰り際、給湯室で、槙野さんがめずらしく日本酒の話を始めた。週末に飲みに行くと、いつも一杯目で「文法はね」と語り出して、店主に苦笑されるらしい。

「なんで槙野さん、こんなに……パーサーが好きなんですか」と、わたしは思いきって訊いてみた。

槙野さんは、少し遠くを見た。

「部品が、生きてるからかな」と彼女は言った。「Choiceとか、Chainとか。あの子たち、ただの道具じゃなくて、組むと、組んだ通りに**動いてくれる**。裏切らない。……人間より、ずっと」

最後のひとことは、冗談みたいに軽かったけれど、軽すぎて、わたしは笑えなかった。給湯室の窓の外は、もう暗かった。

「前任の人も、そう言ってましたか」

訊いてから、しまった、と思った。槙野さんは、湯のみをゆすぐ手を止めなかった。

「あの人はね」と、水音にまぎれるくらいの声で言った。「木の、いちばん深いところまで降りていって——帰ってこなかった人」

それが何のたとえなのか、わたしには、まだ分からなかった。

——あの呪いの式の木が、どれだけ深く、どれだけ高く伸びていて、その底で何が待っているのか。わたしが本当にその枝を降りていくのは、まだ、ずっと先のことだ。
