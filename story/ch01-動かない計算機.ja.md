# 第一章　動かない計算機

いまでも、あの画面の前に座った日を思い出せる。

「これ、たまに止まるんだ」と先輩は言った。たまに、五十三分。

——その式が、わたしの進路をぜんぶ書き換えてしまうなんて、十九のわたしは、まだ知らない。パーサーが何なのかも、知らなかった。

* * *

入社して三日目だった。

わたし——結城灯里は、その春、文系の高校を出て、地元の小さな会社に入った。エンジニア、という肩書きだけは付いたけれど、正直に言えば、配属が決まるまでパソコンは年賀状を作る箱だと思っていた。同期は二人。理系の子はひとりもいなかった。

「特にやりたいことがなくて」と面接で言ったら、面接官は少し笑って、「それでいい」と言った。あとで知ったが、その会社は、人がやりたがらない仕事ばかりが残るような会社だった。

わたしに回ってきたのも、そういう仕事だった。

「『式エンジン』の保守、灯里ちゃんね」

そう言って、髪をひとつに結わえた先輩——槙野さんが、窓のない小部屋の、いちばん奥の机を指した。机の上には、缶コーヒーの輪染みがいくつもついた古いノートが一冊、置き去りにされていた。表紙に、丸っこい字で「計算ルール帳」とだけ書いてある。

「前任の人の?」とわたしが訊くと、槙野さんは少しだけ間を置いて、「まあ、そんなとこ」と言った。その人がどうしていなくなったのか、その日は教えてくれなかった。

* * *

式エンジン、というのが何なのか、わたしにはまるで分からなかった。

槙野さんが見せてくれたのは、ただの黒い画面に白い文字が並ぶ窓だった。そこに、彼女は手早く何かを打ち込んだ。

```
1 + 2 * 3
```

「これ、答えは?」と槙野さんが訊く。

「……七、ですよね。かけ算が先だから」

「正解。じゃあ、機械はどうやって『かけ算が先』だって知るんだと思う?」

わたしは黙ってしまった。考えたこともなかった。だって、それは——当たり前のことだったから。

「うちのこの子はね」と槙野さんは画面を指でつついた。「式を、左から右に、ただ読むんじゃないんだ。読みながら、**意味を組み立ててる**。文章を読むのと一緒。『わたしは／パンを／食べた』って、区切って、誰が何をしたか組み立てるでしょ。あれを、数字と記号でやってる」

「……組み立てる」

「うん。その組み立て係のことを、パーサーっていうの」

パーサー。生まれて初めて聞く言葉だった。手のひらに、知らない小石をひとつ握らされたみたいな感じがした。重さも、かたちも、まだ分からない。

* * *

「で、ここからが本題」

槙野さんはノートの後ろのほうを開いた。ページの隅に、赤いボールペンで、ぐるぐると囲まれた式がひとつあった。長い長い式だった。`if` がいくつも入れ子になっていて、見ているだけで目がすべる。横に、同じ赤で、小さく書いてある。

```
?53
```

「これ、何ですか」

「うちの自慢の、呪いの式」槙野さんはコーヒーを一口飲んだ。「不正検知に使ってる、本物の式。ふだんは一瞬で答えが出る。でも、この式だけ——たまに、五十三分、固まる」

「五十三……分?」

「分」

わたしは画面を見た。槙野さんがその式を貼り付けて、実行を押す。

カーソルが点滅する。一分。二分。

何も、起きない。

「五十三分待つと、最後は諦めて、昔の遅い計算機のほうに切り替わるようになってる。だから業務は止まらない。止まらないんだけど」槙野さんはわたしのほうを見た。「**誰も、なんでこの一個だけ固まるのか、分かってない**」

前任の人も。その前の人も。

ノートの「?53」は、たぶん、その人たちが順番に書き足してきた、降参の印だった。

* * *

その夜、わたしは家に帰って、祖母の作った筑前煮を食べながら、ずっとあの点滅するカーソルのことを考えていた。

祖母は耳が遠いから、わたしの話はだいたい届かない。それでも「会社、どうだ」とだけ訊いてくれる。「うん、機械が、固まるの」と答えると、「お前みたいだな」と笑った。わたしは昔から、知らないことの前で固まる子どもだった。手をあげるのが怖くて、分かっていても黙っていた。

——機械が固まるのは、ほんとうは、何かを一生懸命やっているからなのかもしれない。

そう思ったら、なんだか他人とは思えなくなった。

* * *

翌朝、わたしは恐る恐る、ソースコードというものを開いてみた。意味はほとんど分からない。でも、ひとつだけ、人の言葉で書かれた行があった。コードの中に残された、メモのようなもの。

```
// TODO: なぜ深いネストの式だけ固まるのか不明。再現はするが原因未特定。
//       Unlaxer 側の問題かもしれない。誰か……
```

「誰か……」のあとは、空白だった。

Unlaxer、というのが、この式エンジンの土台になっている部品の名前らしかった。世界のどこかの誰かが作って、ただで配っている、パーサーを組み立てるための道具。その「誰か」に向けて、わたしは生まれて初めて、バグ報告というものを書いた。震える指で、再現する式と、五十三分という数字を添えて。

返事は、その日の夜に来た。たった一行だった。

> …それ、再現する？ｗ

opa、という名前だった。Unlaxer を作った、その人だった。

腹が立つより先に、不思議とうれしかった。世界のどこかに、この呪いを面白がってくれる人が、たしかにいる。

わたしはノートの「?53」の隣に、自分の字で、小さく書き足した。

```
わたしが、継ぎます。
```

——パーサーが何かも知らないくせに。いま思えば、よく書いたものだと思う。でも、あのときのわたしには、それが、生まれて初めて自分から挙げた手だった。
