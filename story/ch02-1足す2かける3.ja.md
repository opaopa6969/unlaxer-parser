# 第二章　1足す2かける3

> 視点：結城灯里
> （手を動かしながら読めます。コードは実際に動く Unlaxer のものです → `story/code/Ch02Arithmetic.java`）

槙野さんが出した宿題は、子どもみたいに簡単に見えた。

「足し算とかけ算だけでいい。`1 + 2 * 3` みたいな式を読んで、答えを出す。それを、自分で組んでみて」

「……電卓を作るってことですか?」

「電卓は答えを知ってる。灯里ちゃんが作るのは、**式の意味を組み立てる係**。答えはそのあと」

槙野さんは、Unlaxer の部品をいくつか、机に並べるみたいに教えてくれた。ぜんぶ、英語の名前がついた小さな道具だった。

- **DigitParser**——数字をひと文字読む子。
- **Choice**——「このどれか」を選ぶ子。`+` か `*` か。
- **OneOrMore** / **ZeroOrMore**——「ひとつ以上」「ゼロ回以上」くりかえす子。
- **Chain**——「これ、つぎにこれ」と順番につなぐ子。

「この子たちはね」と槙野さんは言った。「**生きてる**。レゴみたいに、組み合わせると、もっと大きな子になる。組み合わせ方が、文法」

## 最初の一行が、書けない

レゴ、と聞いて分かった気になったのに。いざエディタを開くと、わたしの手は止まった。

カーソルだけが点滅している。何を、どう、最初に置けばいいのか。部品の名前は分かる。でも、部品を**自分の指でつなぐ**のは、絵を見るのと、まるで違った。中学のとき、解き方を聞けば「わかった」と思えたのに、白紙の答案を前にすると一手目が出なかった——あの感じ。

見かねたのは、槙野さんではなく、となりの席の同期だった。野中くん。わたしと同じ春に入った、文系の——でも、わたしと正反対の子だ。

野中くんは、人が黙って固まっているのを、放っておけない性分だった。本人いわく「沈黙がこわい」。だから、わたしが手を止めると、すぐに横から首を突っ込んでくる。正直、最初は少し、うっとうしかった。でも——黙っていると机の下に沈んでいくわたしを、毎回、首根っこをつかんで引き上げてくれたのは、そのおせっかいだった。

「結城さん、さっきから一文字も打ってないでしょ」と野中くんは画面をのぞきこんだ。「悩むより、まず動かそうよ。間違えたって、機械は怒らないんだから」

「……でも、間違えたのを見られるの、こわくて」

「俺が先に間違えるよ。ほら」彼は、考える前に手が動くタイプだった。「いちばん素直に、左から読むやつ。こう」

彼は、ものの一分で、こう打った。

```java
// 野中スタイル：とにかく動く。数字、そのあと「記号＋数字」をくりかえす。
Parser flat = new Chain(
    new OneOrMore(DigitParser.class),
    new ZeroOrMore(new Chain(
        new Choice(PlusParser.class, MinusParser.class,
                   MultipleParser.class, DivisionParser.class),
        new OneOrMore(DigitParser.class))));
```

動いた。`1 + 2 * 3` を入れると、ちゃんと「1」「+」「2」「*」「3」と、きれいに区切ってくれる。野中くんは、区切ったものを左から順に計算するコードを足して、実行した。

```
1 + 2 * 3  →  9
```

「ほら、で——」と言いかけて、野中くんは止まった。「……あれ。9?」

## 九、という違和感

九。

正しい答えは、七だ。かけ算が先だから。さっき槙野さんにも、当たり前みたいに答えたのに。野中くんの係は、左から順番に、ただ計算しただけ。`1+2` をして、その 3 に `×3`。誰も、かけ算を先にやれとは言っていない。

「言ってない、もんな」と野中くんは頭をかいた。「どこに『先に』って書くんだ、これ」

わたしは、自分のさっきの「手が止まった」のと、彼の「すぐ動いたのに 9」が、ほんとうは同じ場所でつまずいているのに気づいた。**わたしたちは二人とも、機械に「優先順位」を教える場所を、知らなかった。**

`if` で「× が来たら先に」と書けばいいの? でも `1 + 2 * 3 + 4 * 5` になったら? 野中くんは早速 `if` を足そうとして、枝分かれの沼にはまっていった。わたしは、その横で、また固まっていた。中学のあの教室の、机の下のわたしが、こっちを見ている気がした。

## 形を、変える

見かねた槙野さんが、出張帰りの先生を画面ごしに引っぱってきた。柊（ひいらぎ）先生。もとは高校で数学を教えていた人で、説明が、おそろしく噛みくだけて上手い。

「いっぺんに『かけ算を先に』をやろうとするから、苦しいんだ」と柊先生は言った。「**ルールを足すんじゃない。形を変えるんだよ**」

先生は、三階建ての絵を描いた。

```
Expression（式・3階）＝ 項 を { ＋− で } つなぐ      ← 足し算・引き算
Term      （項・2階）＝ 因子 を { ×÷ で } つなぐ      ← かけ算・割り算
Factor    （因子・1階）＝ 数字                          ← ここまで降りて本物の数字
```

「`1 + 2 * 3` を、いちばん上の3階に持っていく。3階はプラスを見つけて、こう区切る。『左の項は **1**、右の項は **2 * 3**』。3階は `2 * 3` の中までは入らない。**かけ算は下の階の仕事だから、丸ごと下に渡す**。渡された `2 * 3` は2階で 6 になって、3階に帰る。3階はやっと、1 たす 6 で——」

「……七」と、わたしと野中くんの声がそろった。

かけ算が先に計算されるのは、「先にやれ」と命令したからじゃない。かけ算が、足し算より**下の階に住んでいるから**。下にあるものは、先に組み上がる。優先順位は、ルールの数じゃなくて、**形の深さ**だった。

## 三階建てを、指でつなぐ

頭で分かっても、コードにする段で、わたしはまた、ためらった。

「野中くん、先に書いていいよ」と言うと、彼は首を振った。「いや。これは、結城さんが書いた方がいい。俺はすぐ手が動くけど、すぐ間違える。結城さんは遅いけど、**いちど分かったやつは、ちゃんと積む**。さっきの 9 で分かった」

なんだか、初めて、自分の「遅さ」を、悪くないものみたいに言ってもらえた。

わたしは、いちばん下から積むことにした。Factor から。下にあるものほど、先に組み上がるなら——コードも、下から書けばいい。

```java
// Factor（1階）＝ 数字。いちばん深いところ。
Parser factor = new OneOrMore(DigitParser.class);

// Term（2階）＝ Factor を ×÷ でつなぐ。Factor の「中身」には立ち入らない。
Parser term = new Chain(factor,
    new ZeroOrMore(new Chain(
        new Choice(MultipleParser.class, DivisionParser.class), factor)));

// Expression（3階）＝ Term を ＋− でつなぐ。いちばん上。
Parser expression = new Chain(term,
    new ZeroOrMore(new Chain(
        new Choice(PlusParser.class, MinusParser.class), term)));
```

書きながら、野中くんが、一行ごとに「なんで?」を挟んでくる。最初はうるさかったけれど、答えているうちに、わたしの中で、ぼんやりしていた理由が、輪郭をもち始めた。

「その Term、なんで factor が二回出てくるの」と野中くん。

「……ひとつ目の factor が、最初の数。ZeroOrMore の中の factor が、`× そのつぎの数` のくりかえし。`2 * 3 * 4` みたいに、何回続いてもいいように」

「ふうん。じゃあ ZeroOrMore って、ゼロ回でもいいんだよな。`5` だけのときは?」

「ゼロ回。だから `5` も、ちゃんと Term になれる。かけ算が無くても、項は項」

「あー」と野中くんは天井を見た。「俺、そこ、いつも『*が来たら』って if 書いて、`5` 単独で落ちるんだよ。ゼロ回を許す、か……」

説明している自分の声を聞きながら、わたしは、教わる側から、ほんの少しだけ、教える側に踏み出している気がした。臆病なわたしでも、誰かの「なんで?」には、答えられる。問いが、わたしの口をこじ開けてくれる。

「結城さん、コメント多すぎ」と野中くんが笑った。茶化す笑い方じゃなかった。「俺、勢いで書いて、あとで『なんで動くんだっけ』ってなるんだよな。そのコメント、半年後の俺にくれない?」

`1 + 2 * 3` を、この三階建てに流す。

```
7
```

ちいさな「7」だった。でも、わたしには、それが光って見えた。野中くんが、ぱちぱちと、小さく手を叩いた。

## カッコは、上階へのエレベーター

「最後に」と柊先生。「`(1 + 2) * 3` は?」

「九です。カッコの中が先だから」

「その『中が先』を、建物のどこに置く?」

今度は、固まらなかった。カッコの中身は、また足し算からやり直せる。だから、いちばん下の Factor に、**上の階へ戻る階段**をつければいい。

```java
// Factor（1階）＝ 数字  または  '(' Expression ')'
//   ※ Expression を自分の中で参照する“再帰”。Unlaxer では LazyChoice で書く（第六章）。
```

「カッコを見たら、いちばん上に登り直す。エレベーターみたいに」と言うと、柊先生はにっと笑った。「いい喩えだ。文法ってのはな、**禁止のリストじゃない。通り道の設計図**なんだよ」

## 自販機の前で

その夜、帰り道の自販機の前で、わたしはなぜか、泣きそうになっていた。

七が出ただけだ。電卓ならボタン三つ。でもわたしの七は、わたしが「形」を理解して、自分の指で、下から積み上げた七だった。中学のあの教室で、解けないまま書き写していた式に、十九で、やっと一手目を置けた。

野中くんは、別の自販機で、ホットの缶コーヒーを二本買って、一本をわたしに放ってよこした。「結城さんのコード、コメントだらけで笑うけど」と彼は言った。「あれ、たぶん、半年後に読むやつのためだろ。俺のは、三日後の俺が泣くやつ」

人の数だけ、コードの書き方がある。野中くんの勢いと、わたしの慎重と。どっちが正解でもなくて、たぶん、混ぜると、ちょうどよくなる。——あとで因幡玲という、もっと違う流派の子に出会って、わたしはそれを、もっと深く知ることになる。

あの呪いの式が、本当はこの「三階建て」の、はるか高い塔みたいな構造をしていて、だからこそ五十三分も固まるのだと知るのは、まだ、ずっと先のことだ。
