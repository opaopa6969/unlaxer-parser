# 第二章　1足す2かける3

> 視点：結城灯里

最初の一週間で、わたしは「パーサーを作る」というのが、どういうことなのか、ほんの少しだけ分かった気になっていた。気になっていただけ、というのは、すぐに思い知らされる。

槙野さんが出した宿題は、子どもみたいに簡単に見えた。

「足し算とかけ算だけでいい。`1 + 2 * 3` みたいな式を読んで、答えを出す。それを、自分で組んでみて」

「……電卓を作るってことですか?」

「電卓は答えを知ってる。灯里ちゃんが作るのは、**式の意味を組み立てる係**。答えはそのあと」

槙野さんは、Unlaxer の部品をいくつか机に並べるみたいに教えてくれた。ぜんぶ、英語の名前がついた小さな道具だった。

- **DigitParser**——数字をひと文字読む子。
- **Choice**——「このどれか」を選ぶ子。たとえば `+` か `*` か。
- **OneOrMore**——「ひとつ以上くりかえす」子。`123` みたいに数字が続くやつ。
- **ZeroOrMore**——「ゼロ回以上くりかえす」子。
- **Chain**——「これ、つぎにこれ」と順番につなぐ子。

「この子たちはね」と槙野さんは言った。「**生きてる**んだ。レゴみたいに、組み合わせると、もっと大きな子になる。組み合わせ方が、文法」

レゴ。それなら、わたしにも分かる気がした。

* * *

わたしは最初、いちばん素直に組んだ。数字があって、そのあとに「記号と数字」がくりかえす。

```
式 ＝ 数字 を OneOrMore、 そのあとに （ ＋か× のChoice、 つぎに 数字 ） を ZeroOrMore
```

動いた。`1 + 2 * 3` を入れると、ちゃんと「1」「+」「2」「*」「3」と、きれいに区切ってくれた。区切ったものを、わたしは左から順番に計算するコードを書いた。1 に 2 を足して 3、それに 3 をかけて……

```
1 + 2 * 3  →  9
```

九。

画面の中の「9」を、わたしはしばらく見つめていた。

正しい答えは、七だ。かけ算が先だから。さっき槙野さんにも、当たり前みたいに答えたのに。わたしの作った係は、左から順番に、ただ計算しただけ。`1+2` をして、その `3` に `×3`。誰も、かけ算を先にやれとは言っていない。

——言っていない。

そこで、ようやく分かった。さっき槙野さんが「機械はどうやって、かけ算が先だって知るんだと思う?」と訊いた、あの意味が。

わたしは、機械に、それを教えていなかった。

* * *

そこから、丸二日、わたしは止まった。五十三分どころじゃない。

区切るところまではできる。なのに、「かけ算が先」を、どうやって部品の組み合わせで表せばいいのか、まるで見当がつかない。`if` で「×が来たら先に計算」と書けばいいの? でも `1 + 2 * 3 + 4 * 5` みたいになったら? その場しのぎの分岐が、頭の中でどんどん枝分かれして、わたしはまた、知らないことの前で固まった。

中学のとき、連立方程式が、ずっとそうだった。

`x` と `y` がいて、式がふたつあって。クラスのみんなは、すっと解いていく。わたしだけ、最初の一手が踏み出せない。どこから手をつければいいのか、分からない。先生に訊けばいいのに、「こんなことも分からないの」と思われるのが怖くて、ノートのはしっこに、解けない式をただ書き写していた。

あのときと、同じ匂いがした。固まる子どものわたしが、机の下からこっちを見ている。

* * *

見かねたのか、槙野さんが、出張帰りの先生をひとり、画面ごしに引っぱってきた。社内の勉強会でときどき話してくれる、白髪まじりの人だった。みんな「金八先生」と呼んでいた。本名じゃない。説明がやたら噛みくだけて上手いから、いつのまにかそう呼ばれているらしかった。

「結城さん、な」と先生はわたしのへたな図を見て、ゆっくり言った。「いっぺんに『かけ算を先に』をやろうとするから、苦しいんだ。**ルールを足すんじゃない。形を変えるんだよ**」

「……形、ですか」

「式を、建物だと思ってごらん」

先生は、三階建ての絵を描いた。

「いちばん上の階。ここは、足し算と引き算の階だ。**Expression**——式、と呼ぼう。この階の住人は、こう考える。『わたしは、**項**を、プラスとマイナスでつなぐだけ。項の中身? 知らないよ。下の階の担当だ』」

```
Expression（式・3階）＝ 項 を { ＋か− で } つなぐ
```

「ひとつ下の階。ここが、かけ算と割り算の階。**Term**——項、と呼ぼう。この階の住人は言う。『わたしは、**因子**を、かけるか割るかでつなぐだけ。因子の中身? 下の階の担当』」

```
Term（項・2階）＝ 因子 を { ×か÷ で } つなぐ
```

「いちばん下。**Factor**——因子。ここまで降りて、やっと本物の数字がいる」

```
Factor（因子・1階）＝ 数字
```

わたしは、まだピンと来ていなかった。先生は、わたしの「9」を、その建物に通してみせた。

「`1 + 2 * 3` を、いちばん上の3階——足し算の階——に持っていく。3階の住人は、プラスを見つけて、こう区切る。『左の項は **1**。右の項は **2 * 3**』。ここがミソだ。3階は、`2 * 3` の中までは入らない。**かけ算は、下の階の仕事だから、丸ごと下に渡す**」

```
1 + 2 * 3
└項┘   └─項─┘    ← 3階は「1」と「2*3」に分けるだけ
```

「渡された `2 * 3` は、2階——かけ算の階——に降りていく。そこで初めて、2かける3で、**6** になる。6を持って、3階に帰ってくる。3階はようやく、1 たす 6 で——」

「……七」

「七だ」

* * *

息が、すっと通った気がした。

かけ算が先に計算されるのは、**「先にやれ」と命令したからじゃない**。かけ算が、足し算より**下の階に住んでいるから**だ。下にあるものは、上にあるものより先に組み上がる。だから、自然と、先に計算される。

優先順位というのは、ルールの数じゃなくて、**形の深さ**だったのだ。深いほど、強く結びつく。

わたしは、自分の作った平べったい一階建ての文法を、三階建てに組み直した。Unlaxer の部品で言えば、Expression という大きな子の**中に**、Term という子がいて、その中に、Factor という子がいる。レゴが、レゴの中に入っている。

`1 + 2 * 3` を入れる。

```
7
```

ちいさな「7」だった。でも、わたしには、それが光って見えた。

* * *

「最後に、ひとつ」と金八先生は言った。「`(1 + 2) * 3` は、いくつだ?」

「……九、です。カッコの中が先だから」

「そう。じゃあ、その『カッコの中が先』を、建物のどこに置く?」

わたしは少し考えて——今度は、固まらなかった。

カッコの中身は、また足し算からやり直せる。ということは、いちばん下のFactorの階に、こっそり**上の階へ戻る階段**をつければいい。

```
Factor（因子・1階）＝ 数字  または  「（ Expression ）」
```

「カッコを見たら、いちばん上の階に登り直す……エレベーターみたいに」

金八先生は、にっと笑った。「いい喩えだ。文法ってのはな、結城さん、**禁止のリストじゃない。通り道の設計図**なんだよ」

通り道の設計図。わたしはその言葉を、計算ルール帳の余白に書き写した。前任者の丸い字の、すぐ下に。

* * *

その夜、帰り道の自販機の前で、わたしはなぜか、泣きそうになっていた。

七が出ただけだ。電卓なら、ボタン三つで出る。でも、わたしが出した七は、わたしが「形」を理解して、自分の手で組み上げた七だった。中学のあの教室で、解けないまま書き写していた式に、十九になって、やっと一手目を置けた気がした。

——あのとき、誰かがこの建物の絵を描いてくれていたら。

そう思って、すぐに打ち消した。いま描いてもらえたのだから、いい。そしていつか、固まっている誰かに、わたしがこの絵を描く側になれたら。

そんなことを、自販機のあたたかい缶を握りながら、ぼんやり思っていた。あの呪いの式が、本当はこの「三階建て」の、はるか高い塔みたいな構造をしていて——だからこそ五十三分も固まるのだと、知るのは、もう少し先のことだ。
