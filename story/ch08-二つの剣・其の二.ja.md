# 第八章　二つの剣・其の二

> 視点：槙野
> （手を動かしながら読めます → `story/code/TinyCalcEmit.java`）

灯里ちゃんには、まだ話していないことが、いくつもある。二本目の剣のことも、そのひとつだった。わたしが、あまり気が進まなかったから。あの剣は、彼が——前任者が——いちばん愛して、いちばん深く迷い込んだ剣だったから。

彼の名前は、ここでは伏せておく。わたしより三つ上で、わたしにパーサーを教えた人だった。いま、わたしが灯里ちゃんに教えているように。

## 鍛える剣

彼は、一本目の剣——木をその場で歩く評価器——を、「優しすぎる」と言った。

「毎回いちから歩くなんて、律儀すぎる。同じ式に何百万回も値が流れるなら、いっそ、その木を**一回、Java の文章に翻訳して**しまえ。`$price * 1.1` を、そのまま Java のコードに書き出して、コンパイルして、機械の言葉にする。二回目からは、歩かなくていい。**機械が、じかに走る**」

一本目が、その場で木を歩く剣なら、二本目は、木を一度、刀に**鍛え直して**から振る剣だ。鍛えるのに、火がいる。コンパイル、という火が。でも鍛えてしまえば、あとは、ただ速い。

## 葉を、写すな。翻訳しろ

二本目には、一本目にはない、いやらしさがある。

灯里ちゃんが、初めて翻訳係を書いたとき。木を歩いて、`＋` を見たら Java の `+` を書き、数字を見たら数字を書く。素直に、見たものを、そのまま写した。`$price + $price * $tax / 100` から、こう出てきた。

```
(($price)+($price*$tax/100))
```

きれいに見える。でも、これは——**Java として、一文字も通らない**。Java に、`$price` なんて変数は、ない。`$price` は、わたしたちの言語の中だけの名前。木の葉を、そのまま写したら、Java じゃない、何か別の言葉が出てくる。

「歩く剣は、`$price` に着いたら**文脈に値を訊いた**でしょ」とわたしは言った。「鍛える剣は、訊くんじゃなくて、**『あとで文脈に訊け』という Java のコードを書く**の。`$price` を見たら、`ctx.get("price")` って書く。翻訳するの。写すんじゃなくて」

```
((ctx.get("price"))+(ctx.get("price")*ctx.get("tax")/100))
```

これなら、Java として通る。コンパイルできる。走る。

> **手を動かす人へ。** この「ダメな生成（写す）」と「正しい生成（翻訳する）」の対比は、`story/code/TinyCalcEmit.java` で並べて見られます。葉をそのまま写すと `$price` が残ってコンパイルできず、`ctx.get(...)` に翻訳すると通る。**生成コードのバグは、走らせるまで気づきにくい**——その最初の一歩を、手で。

## 汚い、書き直して

灯里ちゃんが、最初に出した Java を、黒木さんに見せたことがあった。黒木さんは寡黙な人だ。長いあいだ無言で読んで、ひとことだけ言った。

「……汚い。書き直して」

灯里ちゃんは、しゅんとした。でも黒木さんは、めずらしく続けた。「`(a)+(b)` の、要らないカッコ。`if` の翻訳の、同じ枝が二回。これ、機械は動く。動くけど——**半年後のあんたが読めない。半年後のあんたも、ユーザーだ**」

半年後の自分も、ユーザーだ。灯里ちゃんは、それをルール帳に書き写していた。彼女は、何でも書き写す。彼も、そういう子だった。

## 二本の剣を、合わせる

二本の剣を、灯里ちゃんは、両方打てるようになった。おもしろいのは——二本で同じ式を斬ると、たまに、ちがう血が出ることだ。歩く剣では正しいのに、鍛える剣では、わずかにずれる。翻訳のどこかが、歩く順番とちがってしまう。

`10 - 2 - 3`。歩く剣は、左から、`(10-2)-3 = 5`。でも、翻訳を一か所まちがえて `10-(2-3)` と書き出すと、Java は素直に `11` を返す。同じ式。ちがう答え。どっちかが、嘘をついている。

灯里ちゃんは、その「ずれ」を、一つずつ潰していった。歩く剣の答えを「正解」と決めて、鍛える剣を、それに合わせる。二本が、同じ答えを返すまで。わたしたちは、それを**パリティ**と呼ぶ。二本の剣が、いつも同じ血を出すこと。

その作業を見ていて、わたしは、彼を思い出していた。彼も、二本の剣をぴったり合わせることに、取り憑かれていた。「同じ式は、どっちの剣でも、同じ答えでなきゃ嘘だ」。正しい。正しいけど、彼はそれを、いちばん大きな式で——あの、五十三分の式で——やろうとして、深みに入っていった。

歩く剣で、あの式を斬ろうとすると、五十三分、固まる。鍛える剣で斬ろうとすると、そもそも鍛える前の、木にする段階で、固まる。彼は、木にもならない式を、なんとか木にしようと、Unlaxer のいちばん奥まで降りていった。そして、ある朝、来なくなった。

体をこわした、と聞いた。それだけだ。彼が悪いんじゃない。あの式が悪いんでもない。ただ——誰も、なぜあの一本だけが固まるのか、分からなかった。分からないものを、ひとりで抱えるのは、つらい。わたしは、それを知っている。

## ロープのこっち側

だから、正直に言うと。

わたしが灯里ちゃんに、二本目の剣をゆっくりとしか教えなかったのは——あの子に、彼と同じ深みに、ひとりで降りてほしくなかったからだ。

でも、灯里ちゃんは、もう、ルール帳の隅に書いてしまっている。「わたしが、継ぎます」と。継ぐ、というのは、剣を継ぐことだけじゃない。彼が降りて、帰ってこられなかった、あの深みも、継ぐということだ。

最近、あの子のまわりには、人が増えた。沈黙を放っておけない野中くん。違う流派から赤ペンを入れてくる玲ちゃん。汚いコードを許さない黒木さん。要らないものを消す三上さん。——彼のときには、いなかった顔ぶれだ。

わたしは、冷めたコーヒーを、もう一口飲んだ。

せめて、今度は。今度は、ひとりにはしない。歩く剣も、鍛える剣も、わたしが先に、何度も振って見せる。あの子が深みに降りるときは、ロープのこっち側を、わたしが——いや、わたしたちが、握っている。

そう決めた朝のことを、灯里ちゃんは、たぶん、まだ知らない。
