# 第八章　二つの剣・其の二

> 視点：槙野

灯里ちゃんには、まだ話していないことが、いくつもある。

二本目の剣のことも、そのひとつだった。わたしが、あまり気が進まなかったから。あの剣は、彼が——前任者が——いちばん愛して、いちばん深く、迷い込んだ剣だったから。

* * *

彼の名前は、ここでは伏せておく。わたしより三つ上で、わたしにパーサーを教えた人だった。灯里ちゃんに、わたしが教えているように。

彼は、一本目の剣——木をその場で歩く評価器——を、「優しすぎる」と言った。

「毎回いちから歩くなんて、律儀すぎる。何百万回も同じ木を歩くなら、いっそ、その木を**一回、Javaの文章に翻訳して**しまえばいい。`$price * 1.1` を、そのまま `price * 1.1` っていう Java のコードに書き出して、コンパイルして、機械の言葉にしてしまう。そうすれば、二回目からは、歩かなくていい。**機械が、じかに走る**」

それが、二本目の剣だった。木を、Java のコードに**生成する**剣。

一本目が、その場で木を歩く剣なら、二本目は、木を一度、刀に**鍛え直して**から振る剣だ。鍛えるのに、手間と火がいる。コンパイル、という火が。でも、いちど鍛えてしまえば、あとは、ただ速い。

灯里ちゃんなら、こう言うだろう。「同じ式なのに、二つの実行のしかたがあるんですね」と。そう。同じ木から、二振りの剣が打てる。歩く剣と、鍛える剣。Unlaxer の式エンジンは、その両方を、持っている。

* * *

二本目の剣には、一本目にはない、いやらしさがあった。

木を歩くなら、まちがえても、その場の一回で済む。でも、Java の文章に翻訳するとなると——翻訳が下手だと、**まちがった Java を、何百万回も走らせる**ことになる。しかも、生成されたコードは、たいてい、人が読むようにはできていない。機械が機械のために書いた、ぎっしりした文章だ。バグがあっても、どこにあるのか、見えない。

灯里ちゃんが、はりきって、その翻訳係——コードを書き出す係——を、初めて自分で書いたとき。出てきた Java を、黒木さんに見せたことがあった。

黒木さんは、寡黙な人だ。コードを、長いあいだ、無言で読んだ。それから、ひとことだけ言った。

「……汚い。書き直して」

灯里ちゃんは、しゅんとしていた。でも黒木さんは、めずらしく、続けた。「`(a)+(b)` の、要らないカッコ。`if` の翻訳の、同じ枝が二回。これ、機械は動く。動くけど——**半年後のあんたが読めない。半年後のあんたも、ユーザーだ**」

半年後の自分も、ユーザーだ。灯里ちゃんは、それを、ルール帳に書き写していた。彼女は、何でも書き写す。彼も、そういう子だった。

* * *

二本の剣を、灯里ちゃんは、両方、打てるようになった。

おもしろいのは、二本の剣で、同じ式を斬ると——たまに、ちがう血が出ることだ。歩く剣では正しいのに、鍛える剣では、わずかにずれる。翻訳のどこかが、歩く順番と、ちがってしまう。彼女は、その「ずれ」を、一つずつ潰していった。歩く剣の答えを「正解」として、鍛える剣を、それに合わせていく。二本が、同じ答えを返すまで。

その作業を見ていて、わたしは、彼を思い出していた。

彼も、二本の剣を、ぴったり合わせることに、取り憑かれていた。「同じ式は、どっちの剣でも、同じ答えでなきゃ嘘だ」。正しい。正しいけど、彼は、それを、いちばん大きな式で——あの、五十三分の式で——やろうとして、深みに入っていった。

歩く剣で、あの式を斬ろうとすると、五十三分、固まる。鍛える剣で斬ろうとすると、そもそも、鍛える前の——木にする段階で、固まる。彼は、木にもならない式を、なんとか木にしようと、Unlaxer のいちばん奥まで、降りていった。

そして、ある朝、来なくなった。

体を、こわした、と聞いた。それだけだ。彼が悪いんじゃない。あの式が悪いんでもない。ただ——誰も、なぜあの一本だけが固まるのか、分からなかった。分からないものを、ひとりで抱えるのは、つらい。わたしは、それを、知っている。

* * *

だから、正直に言うと。

わたしが灯里ちゃんに、二本目の剣を、ゆっくりとしか教えなかったのは——あの子に、彼と同じ深みに、ひとりで降りてほしくなかったからだ。

でも、灯里ちゃんは、もう、ルール帳の隅に書いてしまっている。「わたしが、継ぎます」と。

継ぐ、というのは、剣を継ぐことだけじゃない。彼が降りて、帰ってこられなかった、あの深みも、継ぐということだ。

わたしは、コーヒーを、もう一口飲んだ。冷めていた。

——せめて、今度は。今度は、ひとりにはしない。歩く剣も、鍛える剣も、わたしが先に、何度も振って見せる。あの子が深みに降りるときは、ロープのこっち側を、わたしが、握っている。

そう決めた朝のことを、灯里ちゃんは、たぶん、知らない。
