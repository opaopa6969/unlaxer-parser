# 『式を継ぐ者』— 設定資料 (Story Bible)

> パーサーを知らなかった19歳の女の子が、53分間ハングする呪われた式の謎を追ううちに、
> 文法を育て、式エンジンを二つ作り、言語の IDE を生み、最後は **Unlaxer 本体にパッチを送る**までになる、
> 継承と越境の青春譚。査読劇とは独立した作品。Issue: opaopa6969/unlaxer-parser#53

## 文体
- **基本＝一人称・回想形**。大人になった灯里が「あの頃」を振り返って語る。
- **章によって語り手をスイッチ**（多視点）。章頭に視点者を明示（例: `> 視点：因幡玲`）。
  - 玲視点の章（生成派の内側／ライバルの動機・家庭）2章ほど。
  - 槙野視点の章（なぜ Unlaxer 流に賭けたか／前任者との関係）1章。
  - opa視点の超短章（“中の人”の独白＝メタの幕間）1つ。
  - Parr / Odersky は地の文の視点者にはせず、カメオ会話で描く。
- 親密さ＋伏線（終章の patch upstream を最初から仄めかせる）。
- 説明は**中学生にも分かる比喩**を優先。技術は背景として正確に。情景→感情→（さりげなく）技術、の順。

## 規模（想定）
- **全15章**（本筋13章 ＋ 視点スイッチの幕間2〜3章）。
- 1章 ≈ **12〜18枚**（5,000〜7,000字／400字詰め）。
- 全体 ≈ **200〜250枚**（≈ 8〜10万字）の中〜長編。**章ごとに段階生成**。
- ※第1章は導入のため短め（≈6枚）。以降の章はより厚く。

## 主要人物（オリジナル）
- **結城 灯里（ゆうき あかり, 19・女）🕯**：文系高卒、地方の小さな会社の新人。parser を知らない。
  式エンジンの保守を「継ぐ」。引け目＝特別な才能などない。動機＝前任者の遺した**計算ルール帳**と、誰も直せない**53分ハング**。
  口癖「…そもそも、これ何をしてるんですか？」。臆病だが、いちど気になると離せない。
- **槙野（まきの）🍶**：Unlaxer 流の先輩。コンビネータを“生きた部品”として扱う。ヨーダ的、酒で脱線。
  「文法を**感じろ**。木は外から眺めるな、**中を歩け**」。
- **因幡 玲（いなば れい, 20・女）⚙**：別チーム/他社の同年代ライバル。CS 専攻、ANTLR(生成)流。
  「文法は**仕様**だ。道具に生成させろ。手で組むなんて中世だ」。Parr の遠い薫陶。灯里との越境の友情/恋。

## 流派の対比（物語の背骨）
- **合成派 = Unlaxer**：パーサを生きた部品として**組む**。無限先読み・バックトラック・走れる木。霊的祖先 **Odersky**。
- **生成派 = ANTLR**：きれいな**文法から道具に生成**させる。師 **Parr**。
- 二人は同じ問題を別の流儀で解く。断絶と、橋渡し。

## カメオ方針（重要）
- **直接登場OK＝査読劇ネイティブ／実在の人物**：opa（作者）、ソクラテス（手法ペルソナ）、Parr・Odersky（実在のフレームワーク作者＝references）。
- **他作品（小説/ドラマ/漫画）のキャラは実名で出さない**。性格・軸だけ借りて、**オリジナル名の新キャラ**にする。

### 査読劇カメオ
- **opa 🔭**：稀に降臨。バグ report に「…それ、再現する？w」と一行残して去る（反復ギャグ）。終章で初めて本気で応える。
- **ソクラテス 🎭**：思い込みを産婆術で崩す（古典／手法ペルソナとして直接OK）。

### オリジナル脇役（性格を借用・別名）
- **柊（ひいらぎ）先生**：元・高校数学教師、社の勉強会講師。噛みくだく根気の師（“patient teacher”型）。
- **三上（みかみ）さん**：紅茶を片手に「それ、要りますか？」と無駄を斬る怠惰な戦略家（“simplifier”型）。
- **黒木（くろき）さん**：寡黙で潔癖なレビュアー。「汚い。書き直して」（“implementation enforcer”型）。
- **遠山（とおやま）部長**：営業。「で、ユーザーは金を払うの？」現実を突きつける（“business realist”型）。
- **白石（しらいし）さん**：診断好きの先輩。「みんな、嘘をつく」。隠れた依存・単一障害点を嗅ぎ当てる（“diagnostician”型）。ハング事件の閑話で。

## 構造：シェイクスピア5幕 × 英雄譚
- I 日常と召命（四則演算／ハングの噂）
- II 修行と流派（UBNF で文法を育てる／ANTLR との対比）
- III 二つの剣（①評価器＝木を歩く ②Java生成＝書き出して実行）
- IV 呪われた式（指数バックトラック→packrat memo #40→mapToken memo #49）
- V 言語に光を（VSCode/LSP）→ 終章：**Unlaxer 本体へ patch**（opa が本気で merge＝円環）
