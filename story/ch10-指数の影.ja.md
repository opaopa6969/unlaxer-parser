# 第十章　指数の影

> 視点：結城灯里

「同じことを、何百万回」。

白石さんの言葉を地図に、わたしは、パーサーが何をしているのか、その足あとを、一歩ずつ記録した。読むたびに、どの規則を、どの位置で試したか。ぜんぶ、書き出す。

足あとの紙は、すぐに、何万行にもなった。そして、わたしは、ぞっとするものを見た。

おなじ場所で、おなじことを、パーサーが、何度も、何度も、試していた。

* * *

理由は、あの「カッコ」にあった。

わたしの式は、カッコの中に、いろんなものが入れる。数の式かもしれない。比較かもしれない。三項かもしれない。`( ... )` を見たとき、パーサーは、中身が何なのか、最初は分からない。だから——**ぜんぶ、試す**。

「まず、数の式だと思って読んでみよう」。中までぜんぶ読んで……ちがった。`?` が出てきた。これは三項だ。「じゃあ、いちから、三項だと思って読み直そう」。また中までぜんぶ読んで……。

槙野さんが、それを「後戻り（バックトラック）」と呼んだ。

「行き止まりにぶつかったら、分かれ道まで戻って、別の道を試す。迷路の解き方と、同じ。Unlaxer の強みでもあるんだ。どんな複雑な文法でも、根気よく、ぜんぶの道を試してくれる。——でも」

「でも、道が、多すぎると」

「うん。多すぎると、根気が、仇になる」

* * *

柊先生なら、こう描いてくれただろう、と思って、わたしは自分で、迷路の絵を描いた。

ひとつのカッコで、道が、三つに分かれる。数か、比較か、三項か。その三つの道の、それぞれの先に、また**別のカッコ**があって、また三つに分かれる。

```
(   →  数？  →  ( → 3つ
       比較？ →  ( → 3つ
       三項？ →  ( → 3つ
```

カッコが、ひとつ深くなるたびに、道の数が、三倍になる。

ふたつで、三かける三で、九通り。
三つで、二十七通り。
十個、入れ子になっていたら——三を、十回かける。五万九千通り。
あの式は、`if` が、もっとずっと深く積み上がっていた。

「三を、二十回かけると、どうなりますか」とわたしは、声に出して訊いた。

槙野さんが、電卓を叩いた。そして、その画面を、無言で、わたしに見せた。

```
3486784401
```

三十四億。

道が、三十四億通り。パーサーは、そのほとんどが行き止まりだと知らずに、律儀に、一本ずつ、最後まで歩いて、戻って、また次を歩いていた。同じ行き止まりを、何百万回も。

それが、五十三分の正体だった。「指数」という名の、影。深さが一段増えるだけで、影は、三倍、濃くなる。

## 影を、計る

「絵だけじゃ信じられないでしょ」と槙野さんが、小さな練習用の文法をひとつ持ってきた。各 `(` で「これは A か? B か?」と、両方フルに試してしまう、わざと曖昧な入れ子文法。終端のない深いネストを食わせると、あの迷路がそのまま起きる。

野中くんが、深さを変えながら、時間を計った。彼は、こういう「とにかく回して計る」のが得意だ。

```
深さ      メモ化OFF      メモ化ON
8           149ms          25ms
10          112ms           3ms
12          691ms           2ms
14         1017ms           0ms
16         4087ms           0ms
```

「うわ」と野中くん。「OFF、深さが 2 増えるごとに、だいたい倍になってる。14 で 1 秒、16 で 4 秒……18 なら?」

「たぶん十数秒」とわたし。「20 なら、分。あの式は、もっとずっと深い」

数字が、目の前で、倍々に膨らんでいく。五十三分が、急に、絵空事じゃなくなった。これは比喩じゃない。**いま、この机で、影は、ほんとうに三倍ずつ濃くなっている**。

（右側の「メモ化ON」が、ずっと 0 のままなのに、わたしはまだ気づいていなかった。——それが、次章の魔法だ。）

> **手を動かす人へ。** この爆発、`story/code/PackratDemo.java` で、あなたの机でも起こせます。
> ```
> CP=$HOME/.m2/repository/org/unlaxer/unlaxer-common/3.0.11/unlaxer-common-3.0.11.jar
> javac -cp "$CP" -d out story/code/PackratDemo.java && java -cp "out:$CP" PackratDemo
> ```
> 深さを 18、20 と上げると、OFF 側がどこまで粘れるか——あなたの PC の忍耐を、ぜひ試してください。**戻ってこなくなったら、それが五十三分の入口です。**

* * *

わたしは、玲に、この迷路の絵を送った。「ANTLR なら、これ、どうなるの」と。

玲の返事は、少し、誇らしげで、少し、正直だった。

「ANTLR は、分かれ道で、**先に、ちょっとだけ覗く**の。『この先、`?` があるな。なら三項だ』って、当たりをつけてから、一本だけ歩く。だから、三十四億通りは、試さない。——そこは、生成派の勝ち。胸を張って言える」

「じゃあ、玲のほうが」

「でも」と、彼女は続けた。「『先に覗く』のが効かない文法も、ある。覗いても、どっちか決まらない、ほんとに曖昧なやつ。そういうのは、ANTLR でも苦しむ。それに——覗くための賢さは、ぜんぶ、**道具の奥に隠れてる**。あなたが今、足あとを一行ずつ読んで犯人を突きとめたみたいなこと、ANTLR の中では、やりにくい。隠れてるから」

歩く者には、隠れていない。

わたしは、ふと、自分の最初の発表のことを思い出した。「手で組んだから、どこで間違えたか、手でたどれた」。あのとき玲が、ひっかかった、あの一言。いま、わたしは、三十四億通りの迷路の、犯人を、足あとから、手でたどっていた。隠れていなかったから。

* * *

「で」と槙野さんが、コーヒーの缶を、こん、と置いた。「犯人は分かった。三十四億の後戻り。——どう、捕まえる?」

わたしは、迷路の絵を、じっと見た。

道が、多いのが問題じゃない。**同じ行き止まりを、何度も、いちから歩き直す**のが、問題だった。一度「この道は、この位置で、行き止まりだった」と分かったなら——二度目は、歩かなくても、いいはずだ。

「……一回、行き止まりだったところは」とわたしは、ゆっくり言った。「覚えておけば、いいんじゃ、ないですか。『ここは、もうダメだった』って。二度目に来たら、歩かずに、『ここはダメ』って、すぐ言う」

槙野さんの手が、止まった。

彼女は、わたしを見て、それから、天井を見て、小さく、笑った。泣くのを、こらえるみたいに。

「……それ。彼も、最後に、それを言ってた。**記憶させればいい**って。でも、間に合わなかった。やり方が、分からないまま」

わたしは、ルール帳を開いた。「?53」の、すぐ下の、自分の字。「わたしが、継ぎます」。

その下に、もう一行、書き足した。

```
ここは、もうダメだった——を、覚えさせる。
```

——それが「記憶という魔法」、パックラット・メモ化と呼ばれるものへの、わたしの、最初の一歩だった。あの人が、手を伸ばして、届かなかった一歩。わたしは、その手の、すぐ先にいた。
