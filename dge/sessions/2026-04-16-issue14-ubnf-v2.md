## DD-001 改訂版（最終確定）

```ubnf
AtomicElement ::=
    GroupElement | OptionalElement | RepeatElement | ErrorElement | TerminalElement | QuantifiedRef ;

// @mapping なし透過: UBNFMapper が suffix を見て型を決定
QuantifiedRef ::=
    [ IDENTIFIER @namespace '.' ] IDENTIFIER @name
    [ '+' | '?' | '*'
    | '{' Digits @min [ ',' [ Digits @max ] ] '}'
    | '%' AtomicElement @separator
    ] ;
```
PrimaryAtomicElement 廃止。UBNFAST 変更なし。
